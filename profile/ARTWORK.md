# UniAI profile artwork

## Direction

An editorial student research studio: the official geometric logo, orange and purple light, cinematic sculpture, flowing wave fields, orbital particles, terminal details and connected project boards. All department and roadmap information also appears as ordinary README text.

## Reference research

Observed on 15 November 2026. These are design references, not copied templates or artwork.

- [DenverCoder1 profile](https://github.com/DenverCoder1/DenverCoder1): strong header hierarchy, typing subheader, grouped navigation and collapsible content.
- [Platane profile](https://github.com/Platane/Platane): a self-contained animated illustration with explicit dark/light image variants.
- [ryo-ma profile](https://github.com/ryo-ma/ryo-ma): modular graphical cards. UniAI's boards show actual departments and explicitly proposed initiatives rather than activity statistics.
- [Capsule Render](https://github.com/kyechan99/capsule-render): wave silhouettes and visually continuous section transitions. UniAI's wave paths and animation are custom SVGs committed here.
- [RyMe.md](https://github.com/ryanpolasky/ryme.md): terminal and blueprint treatments with self-contained SVG motion.

No source code, illustrations or assets from these repositories were copied.

## Illustration prompt

Use case: stylized-concept. Create an original ultra-refined cinematic 3D brand illustration for UniAI, a university AI student organisation. Wide landscape 3:2 or 16:9 composition. A sculptural open geodesic dodecahedron made from precise electric orange #F7941D tubular edges floats over a black obsidian studio platform; inside is an elegant purple #A04EDB frosted glass polyhedral core. A beautifully flowing silky orange ribbon and a thin violet ribbon orbit the sculpture, sweeping across the foreground like sine waves. A few purposeful small geometric satellites suggest ideas connecting; no clutter. Art direction: high-end experimental design studio, masterful architectural product cinematography, physically plausible 3D render, brushed dark metal, glass caustics, subtle microtexture, soft reflections, restrained haze, beautiful falloff. Strong low-key side lighting with warm amber key, purple rim, dark black #0B0B0D environment. Camera 65mm lens, three-quarter perspective, careful depth of field, dramatic but precise, premium editorial, no sci-fi interface, no robot brains, no cliché circuit board, no text, no typography, no fake logos, no watermark. The main geometric sculpture should occupy right-middle with breathing room, ribbon draws eye from left foreground toward it. Must feel crafted and sculptural, not generic AI stock art. This is a brand-inspired illustration, not a replacement logo.

## Motion and GitHub support

SVG motion uses inline CSS keyframes. All animated SVGs include static reduced-motion fallbacks. Text uses system font stacks. GitHub README content cannot run JavaScript, mouse parallax or scroll-controlled horizontal movement. No companion website is part of this delivery.

The typing subheader and badges are external image services. The custom artwork is served directly from this repository. The core information remains readable without those optional external images or SVG animation.

GitHub applies its own background colour to inline images. The `wave-seamless` and `mission-seamless` variants and the footer wrapper match GitHub's standard dark (`#0D1117`) and light (`#FFFFFF`) canvas to avoid a visible image plate. The original wave and mission exports retain true transparency. Other custom GitHub themes may use different canvas colours.
